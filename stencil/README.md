# Stencil

Template management and validation.

## Overview

Stencil helps you create and manage card templates, which define default structures and constraints for new cards. Templates ensure consistency and enforce rules during card creation.

## Status

⚠️ **Phase 3 Tool** - Currently stubbed, full implementation coming soon.

## Planned Commands

- `stencil new` - Create template card
- `stencil list` - List all templates
- `stencil show` - Display template details
- `stencil validate` - Check cards against template constraints

## Installation

```bash
cargo install --path stencil
# or
cargo build --release --bin stencil
```
