# Porter

Import and export cards in various formats.

## Overview

Porter handles importing cards from external sources and exporting cards to standard formats (JSONL, CSV, Markdown) for backup, sharing, or migration.

## Status

⚠️ **Phase 3 Tool** - Currently stubbed, full implementation coming soon.

## Planned Commands

- `porter export` - Export cards to JSONL/CSV/Markdown
- `porter import` - Import cards from JSONL/CSV/Markdown

## Installation

```bash
cargo install --path porter
# or
cargo build --release --bin porter
```
